# Design System
Use a stable enterprise shell, collapsible navigation, compact command bar, dense work canvas, strong tables and consistent record layouts.

## Palette
Navy `#132A4F`, blue `#2457D6`, red `#C83B3B`, canvas `#F6F8FB`, surface `#FFFFFF`, text `#182230`, muted `#667085`, border `#DDE3EA`, success `#168A5B`, warning `#C87912`, critical `#C43C3C`.

Status: blue in-progress, green completed, amber attention, red blocked, grey inactive, purple authorised exception.
