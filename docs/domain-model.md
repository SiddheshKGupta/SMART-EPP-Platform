# Domain Model
Shared: Employer, Employee, OEM, Distributor, Reseller, Product, Device, Lease, Lot, Programme, Scheme, Document, User, Role, Workflow, Approval, Exception, Audit Event and Financial Event.

Subvention: Employer Programme, Scheme Version, Purchase Transaction, Eligibility Decision, Claim Batch, Claim Transaction, OEM Submission, OEM Response, Rejection, Representation, Invoice, Receipt, Allocation, Accounting Event and Reconciliation Break.

Hierarchy: OEM → Scheme → Employer Programme → Purchase Transaction → Claim Batch → OEM Response → Invoice → Receipt → Accounting → Closure.
